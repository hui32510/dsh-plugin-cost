# dsh-cost

我在 DeepSeek Harness 的输入框下面加了一个小胶囊，就落在那条统计行上（和「轮次/步数」「token/缓存命中」同一排）。它显示三样东西：账户余额、这一轮（或整条对话）的估算花费、还有离高峰/空闲切换还剩多久。左键点开是近七天的消费，右键可以换图的样式、换花费的口径。

之所以做这个：原来的 `dsh-balance` 把余额放在侧边栏底部，我平时基本看不到；而且它只有余额，看不出这一轮到底花了多少钱。所以我在它的基础上加了「本轮花费」「本次对话花费」「空对话也显示」和「高峰倒计时」，并把这个胶囊挪到了输入框下面。

| | |
|---|---|
| 适用 | DeepSeek Harness **0.2.x 桌面版**（我在 `0.2.1-rc.2` 上测过） |
| 运行环境 | Node ≥ 22.18，用 DSH 自带的运行时就行 |
| 许可证 | MIT |
| 来源 | 基于 [`@andrecgoncalves/dsh-balance`](https://github.com/andregoncalves/dsh-balance) v0.4.3 修改，原作者 Andre Goncalves |

## 效果

```
◷ 4 轮 115 步 · 263 tok/s   ▤ 14.3M tok · 缓存命中 99%   [鲸鱼] ¥8.80 · 本轮 ¥0.0042 ● 13h3m   ◔ 21%
```

- `¥8.80` —— 账户余额，跟着当前模型的服务商走：DeepSeek、OpenRouter、Moonshot、Zhipu、MiniMax 都支持。
- `本轮 ¥0.0042` —— 最后一个完成轮次的估算花费，可以切成 `本次 ¥0.5231`（整条对话累计）。
- `● 13h3m` —— 离下次高峰/空闲切换还有多久。红点是高峰，绿点是空闲。

还没发第一条消息的新对话里，它照样在，只是不显示钱（本来也没花钱）：

```
[鲸鱼] ¥8.80 ● 13h3m
```

## 功能

| 功能 | 说明 |
|---|---|
| 余额 | 按当前模型的服务商去查；没配 key 就显示 `—`，不影响别的功能 |
| 花费 | 本轮或本次对话累计，右键切换 |
| 峰谷状态 | 红/绿点 + 倒计时，鼠标悬停显示「距空闲 45分钟」这样的全称 |
| 近七天 | 左键弹出柱状图，配三格摘要（今日 / 日均 / 余额可用） |
| 图形样式 | 逐日数值，或高峰·空闲堆叠；选过会记住 |
| 空对话 | 同一个胶囊，不显示金额，左键右键照常能用 |

## 安装

先装好 DSH 桌面版。这个插件不走 npm，是直接从仓库链进 DSH 的 profile：

```powershell
git clone https://github.com/hui32510/dsh-cost.git
cd dsh-cost
.\install.ps1
```

装完重启 DSH 就能看到。

如果提示「禁止运行脚本」，换这句：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

它做的就是把仓库链进 profile：往 `package.json` 里加一行 `link:` 依赖，再在 `node_modules` 下建一个指向仓库的 junction。想手动做的话，等价于：

```json
"dependencies": { "dsh-cost": "link:<仓库绝对路径>" },
"dsh": { "profile": { "bundles": ["…", "dsh-cost"] } }
```

以后更新：`git pull` 之后重启 DSH 就行，不用重装。

如果哪天 `node_modules/dsh-cost` 变成了普通副本（不再是链接），改完 `lib/` 要跑一次 `apply.ps1` 同步，然后重启。

## 使用

### 胶囊

- 位置在输入框下面那条统计行，和 DSH 自带的两项统计排在一起。
- 鼠标扫过不会有提示，左键点一下才打开浮层。
- 余额跟着模型走：切到 OpenRouter 的模型，显示的立刻就是 OpenRouter 的余额。

### 空对话

点「新会话」、还没发消息的时候，那条统计行本来是空的（CSS 会把它隐藏）。我把同一个胶囊放进去了，位置、字号、间距跟有对话时完全一样：

- 左键照常出七天图，右键照常出菜单。菜单里选的「消费显示」会记下来，等这条对话有了轮次就按选的那样显示。
- 发出第一条消息后，正式的那个出现，空对话这个立刻让位，不会同时出现两个。

### 左键：近七天

浮层出现在胶囊正上方，上方放不下就翻到下面。里面是柱状图加三格摘要：

- 图里那条虚线是日均，超过它的柱子一眼就能看出来；柱顶标当天的金额，今天那根整根点亮。
- 当天没花钱就不画柱子，也不标 0，免得天平线上多出一条没意义的短线。
- 三格是：今日、日均、余额可用（余额除以日均，向下取整）。
- 如果账户不是人民币（OpenRouter 是美元、MiniMax 是配额），第三格改成「本周轮次」—— 人民币日均没法除。
- 关闭：再点一下、点别处、或者按 `Esc`。

### 右键菜单

两组，各带子菜单：

- **样式** —— 七天图怎么画。
  - 逐日数值（默认）：一天一根柱，柱顶标金额。
  - 高峰 / 空闲堆叠：每根柱拆成高峰（浅色）和空闲（绿色）两段，顶部有图例。
- **消费显示** —— 胶囊上那笔钱按哪种口径算。
  - 显示本轮消耗（默认）：最后一个完成轮次的。
  - 显示本次对话总消耗：从第一轮算到现在，正在跑的那轮也算进去。

选了立刻生效，记在浏览器的 `localStorage` 里，刷新和重启都还在。

> 空对话里菜单底部会多一行灰字「花费显示将在对话开始后生效」—— 那个本来就不显示金额，选了也看不出变化。

## 配置单价

默认按人民币/百万 token 的高峰价算：输入 2、缓存读 0.2、缓存写 2、输出 3；空闲时段自动减半。这只是估算，可以按自己的套餐改，两种方式：

改 profile 的 `cordis.patch.yml`：

```yaml
- id: dsh-cost
  name: "dsh-cost"
  config:
    prices:
      deepseek-flash: { input: 2, cacheRead: 0.2, cacheWrite: 2, output: 3 }
      default: { input: 2, cacheRead: 0.2, cacheWrite: 2, output: 3 }
```

或者写个价格文件 `~/.dsh/dsh-cost-prices.json`，改完立刻生效、不用重启：

```json
{
  "deepseek-flash": { "input": 2, "cacheRead": 0.2, "cacheWrite": 2, "output": 3 },
  "default": { "input": 2, "cacheRead": 0.2, "cacheWrite": 2, "output": 3 }
}
```

单位是「元 / 100 万 token」，按高峰价填，空闲时段自动 ×0.5。

## 关于这几个数字

- **都是估算，不是账单。** 我按 token 数乘单价算，缓存命中、批量折扣、订阅套餐这些它都不知道。
- 每笔调用按**它自己发生的时间**判高峰还是空闲，所以昨天的高峰调用今天看还是高峰价，跨过峰谷的一轮也会分开算。
- 三条数据来源不一样：余额查服务商接口，本轮和本次读当前对话的事件，近七天是把本地会话日志翻出来折的。
- fork 出来的对话会带上父对话的历史，那部分算在父对话上，不会重复计费。
- 如果是按订阅计费、不按 token 扣钱，这个数字可以当成「等价 token 成本」，用来横向比较每轮开销。
